# Токенцы

В меню miniapp пункт «Токенцы…» открывает журнал новых операций этой установки.
Столбцы: операция, время запуска, длительность, потраченные токены. Сверху —
сумма известных входных и выходных токенов. Журнал доступен и при остановленном
сервере; окно обновляется каждые пять секунд и по кнопке «Обновить».

Одна строка объединяет обращения к модели внутри одной операции. Повторное
пользовательское действие создаёт новую строку. Поддержаны «Спросить», AI-проверки,
навык переименования слоёв, planning и существующие исполнители генерации.
Детерминированная «Проверить» в плагине передаёт только идентификатор операции,
время, длительность и статус: модели она не вызывает, поэтому расход равен 0.
Длительность этой строки измерена в плагине. Недоступный/старый Proxy не задерживает
проверку; её результат и протокол не зависят от телеметрии.

Codex возвращает фактические счётчики в `turn.completed`. Claude использует
итоговый `result.modelUsage`, а при его отсутствии — `result.usage`; сообщения
assistant и итог не складываются. В Claude вход включает обычные токены,
чтение кеша и создание кеша. Для Codex кеш уже является частью входа.
Выходные reasoning-токены повторно не прибавляются.

Если агент не передал полную статистику, строка показывает «Нет данных» либо
`≥ N`, когда известна только часть расхода. Ошибки, отмены и прерывания сохраняются.
AlfaGen пока не имеет согласованного usage-адаптера: его строки остаются без
полного расхода. Расход в деньгах и остаток лимитов аккаунта не вычисляются.

Записи `apollo.token-operation.v1` хранятся отдельными JSON в
`APOLLO_STATE_ROOT/token-journal`. В dev-установке без явного state root —
`.local/token-journal` относительно рабочей папки сервера. Обновление данных
не затрагивает журнал. Тексты вопросов, ответы, макеты и credentials в этот
журнал не записываются. Старые диагностические usage receipts не импортируются.
После аварийного завершения незакрытые строки помечаются как прерванные при
следующем запуске; неизвестная длительность не заменяется временем простоя.

Локальный `GET /usage` возвращает строки и число повреждённых записей.
`POST /usage/local` принимает только фиксированную детерминированную проверку
с нулевым расходом. Повтор с тем же идентификатором и теми же полями идемпотентен;
другие значения отклоняются. Ошибка записи журнала не прерывает операцию агента.

Регрессии: `test/token-journal.test.js`, `test/token-journal-native.test.js`,
`test/model-selection.test.js`; клиент плагина — `tests/token-journal-client.test.js`.

Форматы провайдеров: [Codex JSON events](https://learn.chatgpt.com/docs/non-interactive-mode),
[Claude usage](https://code.claude.com/docs/en/agent-sdk/cost-tracking).
